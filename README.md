🩸 LifeLink – Blood Bank & Donor Connect

LifeLink is a modern, responsive blood bank and donor connection web application designed to connect blood donors, patients and blood banks. The platform helps users find donors, post emergency blood requests and explore blood availability in a simple and user-friendly environment.

🌐 Live Demo

🔗 Website: https://heartbeat-donor-network.lovable.app/

✨ Features

- 🩸 Donor Directory – Find blood donors by blood group, city and availability.
- 🚨 Emergency Blood Requests – Post and view urgent blood requirements.
- 📝 Donor Registration – Register as a blood donor without creating an account.
- 🏥 Blood Bank Directory – Explore blood banks and their contact details.
- 📊 Blood Availability Dashboard – Visual representation of blood stock across all blood groups.
- 🔍 Smart Search & Filters – Search donors and blood banks easily.
- 📱 Responsive Design – Works on mobile, tablet and desktop.

🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS

🎯 Project Objective

The main objective of LifeLink is to make the process of finding blood donors and requesting blood more accessible through a digital platform.

This project demonstrates how web technologies can be used to create a community-driven healthcare solution that promotes blood donation and supports emergency communication.

⚠️ Disclaimer

LifeLink is an educational and demonstration project. Donor details, blood requests and inventory information may contain sample data and are not necessarily verified or real-time.

The platform is not a substitute for professional medical advice or official blood bank services. Donor eligibility and blood availability must be confirmed by authorized medical professionals.
